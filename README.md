# Loop and Diffusion

研究目标：从循环 Transformer 与 diffusion / flow 的共同计算结构出发，识别可证明的对应关系、共同问题与可迁移方法，进而发展高效的多轮计算、训练与状态记忆机制。

研究快照：2026-11-24。本文档库区分数学推导、原作者报告的结果、结构推论与待验证研究假说。

## 研究主轴

1. **共享参数与跨轮相关性**：参数复用同时影响残差统计、参数扰动、梯度和状态分布。
2. **可持续更新的状态与记忆**：识别当前读出不可见、但后续计算需要的信息；研究跨轮读写和训练信用。
3. **可组合与可调预算的计算**：区分延长算法过程与细化同一生成轨迹，研究区间算子、停止策略和内外层计算分配。

Loop 是计算组织方式，diffusion 是生成概率路径与更新的组织方式。两者的结合应保留真实状态接口与训练目标，而不是只匹配表面上的重复调用。

本仓库是研究资料与待验证问题的起点，目前没有声称已复现 GLM 或完成大模型实验。
