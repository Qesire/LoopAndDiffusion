# 从共同抽象到可验证的研究问题

2026-11-24。研究路线由 [数学基础](01_mathematical_correspondences.md)、[GLM](02_glm_and_learning_mechanisms.md)、[共性问题](03_shared_problems_and_transfer.md) 导出。这里记录待验证方案，不是实验结果。文献与既有方法见 [索引](../references/README.md)。

## 1. 主问题与优先级

| 主线 | 要解释的现象 | 最具区分力的观测 | 优先级 |
|---|---|---|---|
| 共享误差与跨轮相关 | 复用为什么产生不同于普通深度的尺度/压缩规律？ | 同一固定权重扰动 vs 逐轮独立扰动；终点交叉项 | P0 |
| 状态与未来记忆 | 前一轮生成了哪些下一轮才有价值的状态？ | 当前读出零空间内的未来敏感方向；保持前向不变的梯度开关 | P0 |
| 可组合计算与预算 | 怎样压缩多轮计算、分配计算并保留任务收益？ | 未见区间分割、内外预算等成本曲线 | P1 |

研究首先使用开放权重、可追踪中间态的 recurrent-depth LM（如 Huginn）及 Looped-DiT/LiFT 的可用实现。GLM-5.4 是工业架构参考；没有其训练代码、权重和日志时，用小型 GLM-like 两轮双记忆模型作结构验证，不宣称复现旗舰。

## 2. 最小公共测量协议

定义实际执行状态 $Z_r=(H_r,M_r)$，明确轴 $b$ 批次、$i$ token/空间位置、$a$ 通道、$r$ 循环、$k$ 采样步。固定权重版本、数据划分、seed、真实执行的预算与调度。记录每轮输入、写入增量、读出、gate、KV 来源与路由、实际延迟和峰值显存。仅在必要的样本和层保存高维张量；其余在线汇总或随机投影。

LM 选择可控依赖长度的多跳关系、算术及真实推理任务；对 diffusion 使用固定条件和噪声、原模型支持的生成设置与对应质量指标。先验证所有 hook 不改变输出，确保连续采样/循环是真实 rollout。离线敏感度用于解释，在线执行用于验证真实收益。

比较须区分同参数、同训练 FLOPs、同推理 FLOPs、同延迟等设定，不将其混成一个结论。共同报告执行次数、有效参数/存储、显存、吞吐、序列输出长度及任务效果。

## 3. P0-A：共享扰动的相干传播

### 推导与假说

根据 $\delta y\simeq\sum_r S_r\delta\theta$、$S_r=C\Phi_{K,r+1}B_r$，共享参数误差在终点包含非平凡交叉项。可预测的假说：在相近单次扰动尺度下，终点误差随跨轮贡献的对齐变化；仅用逐轮激活/输出 MSE 排序会遗漏这一影响。

### 最小实验

1. 对相同输入、同一权重矩阵或低秩扰动方向做真实 dense 基线，记录其全轮残差增量 Gram、每轮路由和最终读出。
2. 在单轮分别注入小扰动 $\delta\theta$；计算终点差分 $v_r$，并比较全轮共享同一扰动。增加逐轮独立零均值扰动组（匹配单轮分布与尺度）。对扰动幅度作少量扫描，判断线性范围与路由切换。
3. 检验 $D=\|\sum v_r\|_W^2$、对角项 $\sum\|v_r\|_W^2$ 和交叉项在未见样本/模块上预测真实终点误差的能力。共享真实量化误差和随机扰动分别报告；有限步最终任务指标作为主验证。
4. 若存在稳定信号，再比较跨轮 pooled calibration、按轮激活尺度、终点联合校准；同一权重仍只存一份，按轮元信息成本计入。

对照 Q-Diffusion、LoopPrune（X7 已直接处理循环位置与共享剪枝）、单轮重构、跨轮联合重构。研究差异应在显式传播交叉项及其可预测性，而非笼统的循环感知校准。若单轮指标和终点交叉项预测无实际差异，先收束方法研究，报告相关性范围。

## 4. P0-B：当前不可见、未来可读的工作状态

### 4.1 机制定位

目标不是仅比较各轮表示相似度，而是识别 $\ker D\pi$ 中被后续计算使用的方向。$\pi$ 可为当前 logits、当前 clean/velocity prediction 或任务变量读出。用随机方向和局部 VJP/JVP 近似当前读出弱响应子空间（记录近似残差）；测量 $D(\pi\circ T)V$、终点 $C\Phi V$，比较等范数随机方向、同答案扰动和改变答案分支的扰动。

在真实网络中控制主状态与 KV：保留当前 query，分别换第一轮稀疏 KV、本轮局部 KV、索引；或保留 KV 而换 query。使用同输入的匹配干预及等范数/等位置对照，避免跨样本 KV 拼接造成不可解释分布外输入。对多跳任务按关系长度分组，观察何种替换破坏新获得的答案。大幅干预可能越过 MoE 路由边界，记录真实执行。

若观察到可重复的未来敏感方向，再训练低秩/有限槽位记忆；在同预算下与无记忆、简单保存当前预测、缓存数值复用比较。以实际任务提升和读写成本为准。

### 4.2 信用分配：前向等价、反向不同

构造两轮共享核心、阶段 gate、首轮 KV 写入与末轮读取的最小模型。先在相同参数和输入下测试以下计算图前向等价，然后分别训练：

| 组 | rollout | 主状态梯度 | 未来损失到历史 KV 写入 |
|---|---|---|---|
| A | 自产 | 保持相同 | detach |
| B | 自产 | 与 A 相同 | 重构恢复 |
| C | 自产 | 与 A 相同 | 可微持久缓存 |
| D | 自产 | 与 A 相同 | 恢复 + 独立低秩写入接口 |

B/C 实现的指定边界内梯度应数值一致，不能把实现差异当作学习算法差异；D 需参数量匹配的通用 adapter 对照。另做 full BPTT 与相同额外继续训练预算的非循环基线。跟踪生成/读出与未来写入梯度余弦、门控和 KV 敏感度，报告最终任务和训练峰值显存/成本。SGF 与 dKV Forcing 是直接的 video-to-loop 迁移起点；是否适用于 LM 需要实测。

## 5. P1：计算组合律与内外层预算

在训练过的可变深度模型上，先测真实教师区间 $T_{b\leftarrow a}$；构造短学生 $S_\phi(Z,a,b)$。相同的输入、初始状态与目标终点下，对比：
- 固定跳步蒸馏；
- 多预算终点蒸馏（LoopFormer 风格）；
- 区间组合训练，分别约束任务读出与完整状态，比较其灵活性；
- 真正跳过计算的退出/预算调度。

保留训练未见区间分割、预算和困难度；测组合缺陷、同后缀终点差异、准确率及真实延迟。若只得到固定捷径，不能称学习了普遍可组合计算。

对 Looped-DiT/LiFT，二维网格扫外部步数 $N$ 和内部循环 $K$，先选少量同成本候选，分别测场估计误差、固定预测器下的离散误差及最终生成指标。拟合局部误差模型只作预测工具，检查增加内部计算的边际收益能否预测真实质量；不默认单调性。若有预测力，再测试按阶段/样本的预算分配。对照现有论文的联合预算设置。

## 6. 研究收束

第一阶段只做 P0-A 和 P0-B 的最小观测，不同时展开大型训练、量化、蒸馏和复杂预算控制。先确定现象是否重复、是否能被算子传播与状态闭合解释；只有发现明确可利用的结构才进入方法实现。P1 可并行做文献与低成本已有 checkpoint 测量。

证据写法：定义对象与干预 -> 说明实际计算图 -> 报告现象和成本 -> 区分推导能解释的部分与需要新证据的机制。主结论来自真实任务 rollout，离线探针用于理解和选择下一步。
